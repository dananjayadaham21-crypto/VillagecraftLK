# VillageCraft LK

A React + TypeScript + Vite frontend prototype for VillageCraft LK.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

The homepage hero, login visual and product gallery use a 5-second product-photo slideshow. The homepage hero blends the product imagery into a single full-width rectangular banner while retaining editable HTML text and controls.

This is a browser-storage prototype. Review backend and authentication configuration before production deployment.
